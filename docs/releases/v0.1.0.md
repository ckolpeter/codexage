First release of **Codexage**, a tiny always-on-top desktop widget that shows your **OpenAI Codex / ChatGPT plan usage limits**.

Codexage 的第一個版本：一個永遠在最上層的桌面小工具，顯示你的 **OpenAI Codex / ChatGPT 訂閱方案使用量**。

> **Unofficial.** Not affiliated with, endorsed by or sponsored by OpenAI. OpenAI, Codex and ChatGPT are trademarks of OpenAI. Codexage reads the same private endpoint the open-source Codex client uses, which may change without notice.
>
> **非官方專案**，與 OpenAI 無關。OpenAI、Codex、ChatGPT 為 OpenAI 的商標。Codexage 讀取的是開源 Codex 客戶端使用的非公開端點，隨時可能變更。

## Highlights / 重點

- **5-hour and weekly limits** with reset countdowns, shared by Codex, ChatGPT Work, Workspace Agents and ChatGPT for Excel. Works when only a weekly limit applies.
  **5 小時與每週額度**和重置倒數（Codex、ChatGPT Work、Workspace Agents、ChatGPT for Excel 共用）。只有每週額度時也能正確顯示。
- **Run-out prediction**, a pace marker on each bar, and "not started" for an unused 5-hour window.
  **用完時間預測**、時間進度刻度；還沒用過的 5 小時額度會顯示「尚未開始計時」。
- **Tray icon with the percentage** (green / amber / red; menu bar text on macOS).
  **系統匣圖示顯示百分比**並變色（macOS 顯示在選單列）。
- **Notifications** at your own thresholds and when a limit resets, with quiet hours.
  自訂門檻通知、額度重置通知、勿擾時段。
- **Usage history** charts and CSV export. **Multiple accounts**, and a **workspace picker** for Business / Enterprise.
  **用量歷史圖**與 CSV 匯出；**多帳號**；Business／Enterprise 可選**工作區**。
- Dark / light / system theme, size, opacity, compact mode, click-through, global hotkey (Ctrl+Alt+X), full-screen auto-hide, edge snapping, offline retry, auto-update.
  深色／亮色／跟隨系統、大小、不透明度、精簡模式、滑鼠穿透、全域快捷鍵（Ctrl+Alt+X）、全螢幕自動隱藏、貼齊邊緣、離線重試、自動更新。
- 10 languages / 10 種語言：English, 繁體中文, 简体中文, 日本語, 한국어, Español, Français, Deutsch, Português (Brasil), Русский.

## Signing in / 登入

- **ChatGPT account (default):** sign in in the window that opens.
  **ChatGPT 帳號（預設）**：在跳出的視窗登入即可。
- **Google accounts:** Google blocks sign-in inside apps. Sign in to chatgpt.com in your normal browser, open `https://chatgpt.com/api/auth/session`, copy everything, and use **Paste sign-in** in Codexage. It is stored encrypted on your computer only.
  **Google 帳號**：Google 會封鎖 App 內登入。請在平常的瀏覽器登入 chatgpt.com，開啟 `https://chatgpt.com/api/auth/session`，全選複製後在 Codexage 按「**貼上登入資料**」。只會加密存在你的電腦。
- **Codex CLI users:** choose *Codex CLI credentials* in Settings to reuse `~/.codex/auth.json` (read-only).
  **Codex CLI 使用者**：可在設定選擇「Codex CLI 憑證」，直接讀取 `~/.codex/auth.json`（只讀取）。

## Known limitations / 已知限制

- A pasted sign-in expires after a while; the widget tells you when to paste again.
  貼上的登入資料會過期，小工具會提示你重新貼上。
- In Codex CLI mode the token is never refreshed by Codexage (that would sign the CLI out). If it expires, run `codex` once.
  Codex CLI 模式不會幫你更新 token（否則會讓 CLI 被登出），過期時請執行一次 `codex`。
- macOS builds are unsigned, so they can't update themselves; you'll get a link to the new release instead.
  macOS 版未簽章，無法自動更新，有新版時會提供下載連結。
- Full-screen auto-hide is Windows-only (macOS hides it on full-screen Spaces by itself).
  全螢幕自動隱藏僅支援 Windows（macOS 會在全螢幕空間自動隱藏）。
