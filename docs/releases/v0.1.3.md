## New / 新功能

- **Account name always shown** above the bars (before, only when you had several accounts), and on the first line of the tray tooltip.
  **一律顯示帳號名稱**：在用量條上方（以前只有多個帳號時才顯示），系統匣提示的第一行也會顯示。
- **Custom names**: Settings → *Display name* for the main account (e.g. "Personal"), and an editable name for every extra account (e.g. "Work"). Empty = the email. A name stays with the email it was given for, so signing in with another account doesn't inherit it.
  **自訂名稱**：主帳號在「設定 → 顯示名稱」設定（例如「個人」），其他帳號可直接在列表中編輯（例如「公司」）；留空則顯示 email。名稱只套用在設定時的那個 email，換帳號登入不會沿用。
- **Mask emails** (Settings → Display): shows `s***@gmail.com`, handy when sharing your screen. Custom names are never masked.
  **遮蔽 email**（設定 → 顯示）：顯示成 `s***@gmail.com`，螢幕分享時很方便；自訂名稱不會被遮蔽。
- With several accounts, **every notification starts with the account's name**, e.g. "Work · Codex Weekly: 85% used".
  有多個帳號時，**每則通知都會標出帳號名稱**，例如「公司 · Codex 每週：已用 85%」。
