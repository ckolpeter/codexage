Usage history now works **per account**, and the tray can watch every account at once. If you installed with the Windows installer, Codexage updates itself (restart from the tray menu when it says the update is ready).

用量歷史現在會**依帳號分開記錄**，系統匣也能同時看所有帳號。用 Windows 安裝版的話會自動更新（系統匣選單出現提示時重新啟動即可）。

## New / 新功能

- **History per account**: every account keeps its own usage curves. With more than one, the history window gets an *Account* picker (main account by default). History you already have is kept and belongs to the main account.
  **歷史依帳號分開**：每個帳號各自記錄用量曲線。有兩個以上帳號時，歷史視窗上方會出現「帳號」選單（預設顯示主帳號）。原有的歷史紀錄會保留，並歸給主帳號。
- **CSV export** has a new `account` column and includes every account.
  **匯出 CSV** 新增 `account` 欄，包含所有帳號的資料。
- **Tray tooltip** shows one line per extra account, e.g. "Work: 5h – · weekly 85%".
  **系統匣提示**中，每個其他帳號各有一行，例如「公司：5 小時 -・每週 85%」。
- **New option** (Settings → Display, shown when you have extra accounts): *Tray shows the highest of all accounts* — so the number goes up when *any* account is running low.
  **新選項**（設定 → 顯示，有其他帳號時才會出現）：「系統匣顯示所有帳號中最高的數字」，任何一個帳號快用完，系統匣的數字都會反映出來。

## Fixed / 修正

- The "runs out at …" estimate of an extra account no longer looks at the main account's history.
  其他帳號的「預計用完時間」不再參考主帳號的歷史資料。
