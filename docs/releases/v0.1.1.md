Two small additions based on real usage. If you installed v0.1.0 with the Windows installer, Codexage updates itself (restart from the tray menu when it says the update is ready).

## New / 新功能

- **Sign-in expiry reminder.** A pasted sign-in (used for Google accounts) can't be renewed automatically. About two days before it expires (or a quarter of its lifetime if that's shorter), Codexage sends one notification and shows "⚠ Sign-in expires in …" with a **Paste again** link on the widget. Clicking the notification opens the paste window. Works for extra accounts too.
  **登入資料到期提醒。** 貼上的登入資料（Google 帳號會用到）無法自動續期。過期前約兩天（若有效期較短則為四分之一），Codexage 會發一次通知，小工具上也會顯示「⚠ 登入資料將在…後過期」和**重新貼上**連結。點通知會直接開啟貼上視窗。其他帳號也適用。
- **Usage limit resets.** The widget shows how many usage limit resets you have. Each one resets both the 5-hour and weekly limits; use one in Codex CLI with `/usage`. Hidden when you have none.
  **額度重置次數。** 小工具會顯示你還有幾次額度重置，每次可同時重置 5 小時與每週額度，在 Codex CLI 輸入 `/usage` 使用。沒有時不顯示。
